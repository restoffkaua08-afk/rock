# Security Policy

## Escopo

O Rock é um runtime de orquestração de modelos desenvolvido com foco em execução controlada.

Na versão V0.1:
- modelos não recebem autoridade implícita para executar efeitos colaterais;
- execução irrestrita de terminal, filesystem e navegador está fora do escopo;
- credenciais devem permanecer fora do Git;
- timeout, retry e custo fazem parte da política de execução.

## Reportando vulnerabilidades

Não publique detalhes de uma vulnerabilidade de segurança ainda não corrigida em uma issue pública.
Envie uma descrição privada aos mantenedores pelo canal de contato indicado no perfil do repositório.
Não inclua chaves de API, tokens, senhas ou dados pessoais no relatório.
