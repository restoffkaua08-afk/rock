# Provedores

Configuráveis: OpenAI, Anthropic/Claude, DeepSeek, Perplexity, Gemini e Ollama.

```text
OPENAI_API_KEY=
ANTHROPIC_API_KEY=
DEEPSEEK_API_KEY=
PERPLEXITY_API_KEY=
GEMINI_API_KEY=
ROCK_OPENAI_MODEL=openai/gpt-5
ROCK_ANTHROPIC_MODEL=anthropic/claude-sonnet-4-5
ROCK_DEEPSEEK_MODEL=deepseek/deepseek-chat
ROCK_PERPLEXITY_MODEL=perplexity/sonar
ROCK_GEMINI_MODEL=gemini/gemini-2.5-flash
ROCK_OLLAMA_MODEL=ollama/llama3.2:3b
```

Confirme os IDs de modelo no provedor antes de trocar os padrões.
