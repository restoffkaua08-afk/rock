# Rock V1.0

Rock 1.0 is the consolidated terminal-first orchestration runtime.

## Release path

The supported path is:

1. CLI receives a task.
2. Rock creates a Task and Session.
3. Council selects configured providers and executes in parallel according to the selected protocol.
4. Responses are normalized into Rock contracts.
5. Evidence, conflicts, critique/adjudication and synthesis are handled by the Council pipeline.
6. Verification checks the resulting synthesis.
7. Corrections are bounded.
8. Runtime events, verification, responses and provider usage are persisted in SQLite.
9. Tools, when used by future workflows, must pass through PolicyEngine and ToolExecutionEngine.
10. MCP-discovered tools remain behind the same policy boundary.

## Safety boundaries

- No unrestricted model-to-OS execution.
- Tool execution requires an explicit policy decision.
- Tool calls have timeouts and call limits.
- Verification/correction is bounded to three attempts.
- Provider failures are isolated.
- Cost limits are run-scoped.
- External coding agents remain explicit integrations rather than implicit execution.

## V1.0 scope

Rock 1.0 is a terminal/runtime product. GUI, voice, phone/WhatsApp, distributed orchestration and a compiled Windows desktop executable are not part of this release.
